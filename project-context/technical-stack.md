# Technical Stack

## Framework
- Next.js 14 (App Router)
- React 18
- TypeScript

## Styling
- Tailwind CSS
- shadcn/ui components

## State
- React hooks (useState, useEffect)
- No external state management needed

## API
- Anthropic Claude API (client-side calls)
- Fetch API for requests

## Deployment
- Vercel
- Environment variables for API key
